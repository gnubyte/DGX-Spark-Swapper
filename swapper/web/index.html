      Trust this box's certificate
      Download the certificate
      
          
      This page and the model API use a self-signed certificate. Apps refuse it until your computer trusts it. Check the fingerprint after downloading — it should match: 
      
          
        
            
      1. macOS: open the .crt, drag it into Keychain Access → System. Select it, right‑click → Get Info → Trust → set "When using this certificate" to Always Trust.
        2. 
            
      2. Windows: double-click the .crt → Install Certificate → Local Machine (or Current User) → Place all certificates in the following store → Trusted Root Certification Authorities.
        3. 
            
      3. Linux / CLI: sudo cp spark-swapper.crt /usr/local/share/ca-certificates/spark-swapper.crt && sudo update-ca-certificates. Check it: openssl x509 -in spark-swapper.crt -noout -fingerprint -sha256.
        4. 
            
      4. Node.js tools (OpenCode, Qwen Code, Claude Code…): also export NODE_EXTRA_CA_CERTS="$HOME/spark-swapper.crt" — Node keeps its own list.
        5. 
            
      5. Python: pass it to the client (httpx.Client(verify="spark-swapper.crt")), or set REQUESTS_CA_BUNDLE for requests.
        6. 
            
      6. AWS EC2 / Lightsail: copy it to /usr/local/share/ca-certificates/ and run update-ca-certificates (bake it into your AMI). An ALB, CloudFront or API Gateway needs a CA-signed certificate instead (Let's Encrypt / ACM). For boto3 from any host: os.environ["AWS_CA_BUNDLE"].
        7.
