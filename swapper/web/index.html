      Trusting the self-signed SSL (AWS / EC2, macOS, Windows, curl)
      
          
      This page (and, if you set it up, the model API front on :11443) uses a self-signed certificate. Browsers and AWS tools will reject it until you add it to a trust store. Download the certificate, then:
      
          
        
            
      1. macOS: open the .crt, drag into Keychain Access → System. Select it, right‑click → Show Info → Trust → set "When using this certificate" to Always Trust. Lock/unlock the System keychain.
        2. 
            
      2. Windows: Certificate Viewer → Import → place in the Trusted Root Certification Authorities store (or per-user), then "Intermediate Certification Authorities" if prompted.
        3. 
            
      3. Linux / CLI: sudo cp spark-swapper.crt /usr/local/share/ca-certificates/spark-swapper.crt && sudo update-ca-certificates. Then curl --cacert spark-swapper.crt https://<host>:8999/ works without -k.
        4. 
            
      4. AWS EC2 / Lightsail (trust from an EC2 host or your AMI): copy the cert to /usr/local/share/ca-certificates/spark-swapper.crt (EC2 AMIs: bake it in, or run on each instance) then update-ca-certificates. For ALB / CloudFront / API Gateway you must use a CA‑signed cert (Let's Encrypt / ACM) — a self‑signed cert can't be attached there; trust it on the client side instead (steps 1–3).
        5. 
            
      5. AWS SDK / boto3 (Python, from any host): import boto3, os; os.environ["AWS_CA_BUNDLE"]=os.path.expanduser("~/spark-swapper.crt"); s3 = boto3.client("s3") — or pass verify=... to requests/urllib.
        6.
